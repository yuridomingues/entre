# ENTRE

Uma coleção de experiências interativas sobre mente, natureza, música, conversa e tempo.

## Experimentos

1. **A árvore que viu tudo**: cinco séculos no tempo de uma árvore.
2. **O mundo que seu cérebro inventa**: ilusões de tamanho, comprimento e contraste.
3. **Anatomia de uma música**: uma composição que pode ser desmontada em camadas.
4. **Por onde uma conversa vai?**: uma frase com vários caminhos possíveis.
5. **Quanto cabe em uma vida?**: anos transformados em semanas.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
